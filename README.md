# 鬧鐘提醒

Android 鬧鐘＋一次性提醒事項。作者：ArchieKUO

- 鬧鐘與提醒放在同一份清單，直接在列上修改，不跳視窗
- 最下面空白列輸入「週五 18:00 倒垃圾」自動辨識日期、時間、重複、內容
- 重複：每天／工作日／週末／僅一次，或點選週一到週日
- 響鈴：稍後提醒、按住 1 秒關閉（防誤觸）
- 開機與改時區後自動重新排程

## 編譯

推到 `main`，GitHub Actions 會自動編譯，APK 放在 `apk` 分支，檔名含版本號（例如 `alarm-v0.1.apk`）。

下載：`https://github.com/<帳號>/<repo>/raw/apk/alarm-v0.1.apk`
