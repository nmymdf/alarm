# 鬧鐘提醒

Android 鬧鐘＋一次性提醒事項。作者：ArchieKUO

- 鬧鐘與提醒放在同一份清單，直接在列上修改，不跳視窗
- 最下面空白列輸入「週五 18:00 倒垃圾」自動辨識日期、時間、重複、內容
- 重複：每天／工作日／週末／僅一次，或點選週一到週日
- 響鈴：稍後提醒、按住 1 秒關閉（防誤觸）
- 開機與改時區後自動重新排程

## 一鍵安靜（v0.16 起合併進來）

同一個 App，桌面上另一個圖示「一鍵安靜」。看電影、音樂會時點一下：鈴聲靜音、勿擾不留例外、螢幕最暗、來電全部拒接（含聯絡人、連續打來的）；再點一下全部還原。
- 安靜中，鬧鐘提醒自己先檢查，不響、不震、不亮螢幕，只留一則沒有聲音的「安靜中略過」通知；重複鬧鐘照常排下一次
- 提前提醒在安靜中也改成沒有聲音
- 程式在 `app/src/main/java/com/archie/alarm/quiet/`（原本的 nmymdf/quiet 停止更新）
- 畫面預覽：每次推送後 `shots` 分支有截圖（Robolectric）
